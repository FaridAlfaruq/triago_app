BAB V HASIL IMPLEMENTASI DAN RENCANA PENGEMBANGAN 
5.1. Hasil Implementasi Purwarupa 
Implementasi untuk realisasi fungsi utama dari sistem TriaGo telah mencakup integrasi 
komponen perangkat keras, pemrograman perangkat lunak, komunikasi dan pemrosesan data, 
hingga pengujian pada subjek sehat secara langsung. Hasil implementasi perangkat 
ditunjukkan sebagaimana pada Gambar 5.1 ketika digunakan oleh subjek dan melakukan 
pengukuran. Saat ini, progress pengerjaan sistem TriaGo telah mencapai progress pengerjaan 
sebesar 70%, di mana komponen utama seperti sensor MAX30105, MLX90614, modul ECG 
Click, STM32 Black Pill, Raspberry Pi 5, PowerBank, dan layar LCD telah terintegrasi menjadi 
satu kesatuan alat yang dapat digunakan. Desain perangkat TriaGo dibuat secara ringkas 
dengan penempatan sensor yang strategis hingga memungkinkan tenaga medis dapat mengukur 
berbagai tanda vital dalam satu alat saja.

(b)

Adapun hasil implementasi lebih detail yang telah dilakukan adalah sebagai berikut: 
1. Pembuatan purwarupa awal dua penjepit berbasis multisensor untuk pengukuran tanda 
vital. 
2. Integrasi sensor MAX30105, MLX90614, dan modul ECG Click dengan mikrokontroler 
STM32 Black Pill dengan pengiriman data secara serial USB ke Raspberry Pi 5. 
3. Integrasi Raspberry Pi 5 dalam menerima data dari mikrokontroler dan menampilkan 
output ke layar monitor. 
4. Pengujian awal pada masing-masing kerja komponen perangkat keras maupun 
pengembangan perangkat lunak. 
5. Membuat model pintar untuk mengukur tekanan darah secara non-invasif dan 
mengklasifikasikan hasil triase berdasarkan input tanda vital dan kesadaran pasien. 
6. Pengembangan database MySQL dan proses pengujian pengiriman data dari perangkat 
keras hingga dapat ditampilkan di website menggunakan Azure App Service. 
 
5.2. Rencana Implementasi 
Dari tahapan purwarupa yang telah dikembangkan menuju implementasi nyata di 
lingkungan nyata Instalasi Gawat Darurat (IGD) memerlukan penyempurnaan perangkat keras, 
pemrosesan perangkat lunak, hingga sistem integrasi IoT. Oleh karena itu, rencana 
pengembangan difokuskan pada aspek peningkatan ketahanan sistem terhadap gangguan

Rincian rencana pengembangan meliputi: 
1. Peningkatan pengolahan sinyal biomedis untuk mengekstraksi data tanda vital pasien

2. Pengambilan dataset primer sebagai validasi data tanda vital, serta model tekanan darah

3. Re-evaluasi model kecerdasan buatan berbasis dataset primer untuk meningkatkan 
akurasi tanda vital dan generalisasi klasifikasi pasien. 
4. Pengembangan desain sistem dan antarmuka (GUI) dengan menerapkan System Usability 
Scale (SUS) untuk memastikan kemudahan pengguna dalam mengoperasikan atau 
menggunakan alat. 
5. Melakukan pengujian implementasi perangkat di lingkungan Instalasi Gawat Darurat 
(IGD) secara langsung.

untuk meningkatkan efektivitas dan optimalisasi alur kerja tenaga medis di IGD.
