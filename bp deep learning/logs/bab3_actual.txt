3.1. Desain Perangkat Keras 
Desain perangkat keras TriaGo dibuat agar tenaga medis bisa mendapatkan parameter 
tanda vital dengan cara yang efisien hanya menggunakan satu perangkat saja seperti yang 
ditunjukkan pada Gambar 3.1. TriaGo dibuat menyerupai penjepit yang biasa digunakan untuk 
mengukur sinyal ECG dengan cara memodifikasi dan menambahkan sensor suhu dan sensor 
PPG di bagian bawah. Selain itu, konfigurasi elektroda ground yang biasa dipasangkan di kaki 
dipindahkan ke lengan sebelah kiri bersama elektroda positif, sedangkan elektroda negatif di 
lengan sebelah kanan. Dengan konfigurasi penempatan sensor ini, tenaga medis dapat 
mengukur tanda vital pasien secara bersamaan dan praktis.

3.1.2. Integrasi Sistem 
Dalam sistem TriaGo, perangkat keras dan perangkat lunak dirancang agar saling 
terhubung secara efisien. Model estimasi tekanan darah menggunakan model deep learning 
dijalakan di Raspberry Pi 5 menggunakan Tensor Flow Lite, sedangkan model XGboost untuk 
klasifikasi triase dijalankan menggunakan runtime ONNX. Cara eksekusi kedua algoritma ini 
memastikan Raspberry Pi 5 bekerja secara cepat dengan hasil yang tetap optimal, walaupun 
dijalankan di Raspberry Pi 5. Dari sisi perangkat keras, mikrokontroler STM32 Black Pill 
bertindak sebagai unit akuisisi tingkat rendah yang membaca data dari sensor MAX30105, 
MLX90614, dan modul ECG Click pada frekuensi sampling sebesar 400 Hz. Data yang

3.2. Desain Perangkat Lunak 
Perancangan perangkat lunak difokuskan pada  pengembangan arsitektur kecerdasan 
buatan yang berjalan pada platform edge computing di Raspberry Pi 5. Desain perangkat lunak 


=== PAGE 14 ===
14 ---
untuk mendapatkan parameter tanda vital tidak semuanya bisa dilakukan secara langsung 
menggunakan persamaan matematis. Klasifikasi tingkat triase dirancang secara otomatis 
menggunakan algoritma perangkat lunak yang pintar berdasarkan tanda vital pasien dan tingkat 
kesadarannya. Tanda vital seperti tekanan darah perlu diekstraksi menggunakan algoritma deep 
learning dan klasifikasi triase pintar perlu diklasifikasikan menggunakan algoritma machine 
learning. 
 
3.2.1 Model Estimasi Tekanan Darah 
Rancangan model estimasi tekanan darah dibangun secara hybrid menggunakan dua 
model utama, yaitu Convolutional Neural Network (CNN) dan Bidirectional Gated Recurrent 
Unit (BiGRU). Model CNN digunakan untuk mengekstraksi informasi morfologi dari sinyal 
ECG dan PPG yang digunakan sebagai input utama, sedangkan BiGRU digunakan untuk 
mengekstraksi informasi temporal sekuensial dua arah antar siklus detak jantung. Selain itu, 
model menggunakan Multi Head Self-Attention (MHSA) untuk mengevaluasi korelasi 
temporal antar-segmen sinyal dan memberikan bobot yang relevan. Hasil akhir tekanan sistolik 
dan diastolik dipisahkan menjadi cabang yang berbeda untuk memastikan prediksi nilai sistolik 
dan diastolik yang lebih optimal seperti rancangan yang ditunjukkan pada Gambar 3.3. 
 
Gambar 3.3 Arsitektur model estimasi tekanan darah 
 
3.2.2 Model Klasifikasi Tingkat Triase 
Model klasifikasi tingkat triase yang dibangun secara otomatis dibangun menggunakan 
algoritma berbasis decision tree, yaitu Extreme Gradient Boosting (XGBoost). Arsitektur 
lengkap model klasifikasi triase ini ditunjukkan pada Gambar 3.4. Model tidak hanya dirancang 
secara pintar menggunakan algoritma XGBoost saja, tetapi juga dilengkapi dengan algoritma 
yang dapat meningkatkan kewaspadaan model apabila terdapat pasien dengan saturasi oksigen 
rendah dan tingkat kesadaran minim. Hasil klasifikasi dipetakan menjadi tiga tingkat 
kegawatdaruratan, yaitu Resusitasi atau pasien kritis, darurat dan non-darurat.
